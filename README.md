# 💰FinanceAI

FinanceAI is an AI-powered personal finance management application that helps users manage their income and expenses efficiently. 
The application provides a user-friendly dashboard to track financial activities and includes an AI chatbot to assist users with financial queries.
---
## Features
- 🔐 User Registration & Login Authentication
- 💰 Add Income
- 💸 Add Expenses
- ✏️ Update Income & Expense Records
- 🗑️ Delete Transactions
- 📈 View Total Income, Expenses & Balance
- 🤖 AI Chatbot for Financial Assistance
- 💾 Store Financial Records in MySQL Database

## Workflow

1. User creates an account and logs in.
2. User adds income and expense details.
3. Data is stored securely in the MySQL database.
4. Dashboard displays financial summary.
5. Users can update or delete transactions.
6. AI Chatbot provides financial assistance and answers user queries.
